Elsa’s kapsalon is a fictional website I that I made for a school project. It’s the biggest and most complex website I’ve made so far. 
The website has 2 different backend systems. One which sends an automated email when a user books an appointment. And one shop system which connects to an SQL database (via PostgreSQL) to handle an order.
The website also has a different layout, depending on the screen you use. On mobile: The elements are laid out differently and the menu is changed to improve the visual representation of the website. 

Here’s some technical information:
frontend languages: HTML, CSS, Javascript
backend language: PHP
Database provider: PostgreSQL

Note: I’m still working on this website. I’m planning to add database interaction for the bookings as well. 

The backend only works on Render https://elsa-kapsalon-website.onrender.com
